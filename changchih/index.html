開口
課堂就動起來

常智是老師的課堂語音助教。翻投影片、出題給全班、把答案畫成圖、在黑板上一步步推導，老師只要說一句話。學生用手機掃碼就能作答，不用下載，也不用登入。

即時語音代理：OpenAI Realtime（WebRTC）負責聽說與 function calling，本機 FastAPI 執行 40 個工具，涵蓋 Office COM、Windows UI Automation、R 統計、Three.js 3D 與 Firestore 即時作答。金鑰全部留在伺服器端。

簡報與檔案

「打開第三章簡報」「下一頁」。翻到有題目的頁面，自動派給學生。

PowerPoint COM（pywin32）。open_file、goto_slide；換頁讀取頁面文字偵測題目。

全班即時作答

文字雲、單選、多選、計算題。學生掃碼輸入暱稱即可，每人限答一次。

Firestore 即時監聽；答案以裝置 ID 為文件 ID，規則只允許 create，達成一人一票。

答案分析

答案即時畫成圖，正確選項標綠。說「為什麼大家這樣答」，常智會指出迷思概念。

R plumber 計算統計與斷詞；R 未啟動時改用 Python。explain_results 用強模型分析。

黑板推導

推導逐行出現，每一步先問學生，老師說「下一步」才繼續。

強模型輸出 LaTeX 步驟 JSON，前端 KaTeX 排版。blackboard／blackboard_next。

3D 立體教具

「投影一個動物細胞」，說到哪個部位就轉過去放大。

強模型產生 Three.js 程式碼，於 sandbox iframe 加 CSP 執行，聚焦以 postMessage 傳遞。

統計驗證

「用 R 驗證中央極限定理」，現場寫程式、執行、出圖。

黑名單檢查後在 callr 子行程執行，10 秒逾時，僅載入 ggplot2。

地圖路線

「從台北車站到北科大怎麼走」，投影真實路線、距離與時間。

伺服器呼叫 Google Routes API，只送折線座標到前端，Leaflet 加 OSM 繪製。

Word 考卷解題

「解第 3 題並寫進去」，紅字插在題目下方，不自動存檔。

Word COM 依題號段落定位；save_word 需口頭確認。

操作電腦

「打開 Excel」「按插入」「輸入：今天作業是第五章」。常智全螢幕時也作用在剛才的視窗。

pywinauto UI Automation 依名稱找元件；中文以剪貼簿貼上並還原；背景追蹤前景視窗。

Safety by Design

會動手，但不會自作主張

規則寫在程式裡，不只靠 AI 自律。右邊可以試著下指令，看常智怎麼處理。

先確認

重要動作一定先問

寄信、刪檔、存檔、按「送出」「刪除」類按鈕前，老師要口頭說「確定」。確認只對同一個目標有效。

第一次呼叫只回傳提示並寫入 pending_confirm；第二次須帶相同目標加 confirmed=true。按鈕名稱以 RISKY_BUTTON 正規式判斷。

拒絕

個資與密碼不碰

不在密碼欄位打字；內容有身分證字號、帳密、卡號時直接拒絕。

guard_args 以正規式偵測身分證、卡號、「密碼：」；密碼欄位以 UIA CurrentIsPassword 判斷。

保護

敏感畫面不截圖

登入頁、網路銀行、密碼管理器的視窗，主動觀察與讀螢幕一律跳過。

依視窗標題判斷敏感視窗；視覺模型輸出再經 redact 遮蔽一次。

保護

金鑰不出筆電

學生手機和投影網頁都拿不到任何金鑰。

瀏覽器只取得短效 Realtime client secret；學生端設定由 Firebase Hosting init.json 提供。

FAQ

常見問題

需要付費嗎？

語音與 AI 模型使用 OpenAI API，依實際用量計費；地圖使用 Google Routes API，也依用量計費。學生作答用的 Firebase 在一般班級用量下通常落在免費額度內。

學生需要帳號或安裝 App 嗎？

不需要。學生用手機掃投影畫面上的 QR code，輸入暱稱就能作答，同一題每人只能答一次。

常智會不會亂操作我的電腦？

刪檔、寄信、存檔、按「送出」這類動作，常智一定先口頭詢問，老師說「確定」才執行。密碼欄位不打字，含個資的內容直接拒絕。

網路斷了怎麼辦？

沒有 AI 連線時，可以用畫面下方的文字指令操作大部分功能。沒有雲端時，學生連上和老師筆電同一個 Wi-Fi 也能作答。

學生的資料存在哪裡？

作答只記錄暱稱和答案，存在 Google 雲端台灣機房；其他學生看不到彼此的答案。課後報告存在老師自己的筆電。

Mac 或 Chromebook 可以用嗎？

目前不行。操作簡報、Word 和其他程式的功能依賴 Windows 與 Microsoft Office，教師端需要 Windows 筆電。學生端則任何裝置都可以。

現在可以正式上課使用嗎？

目前是原型。各項功能都已實際測試，但還沒在真實課堂長時間使用，建議第一次上課前先完整演練一次。
